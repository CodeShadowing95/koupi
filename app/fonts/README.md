# Polices

Polices hébergées dans le dépôt et chargées avec `next/font/local` (voir `app/layout.tsx`), pour que le build ne dépende pas de Google Fonts.

| Fichier | Police | Axes | Licence |
| --- | --- | --- | --- |
| `inter-latin.woff2` | Inter | poids 400 à 700 | [OFL-inter.txt](OFL-inter.txt) |
| `bricolage-grotesque-latin.woff2` | Bricolage Grotesque | poids 700 à 800 | [OFL-bricolage-grotesque.txt](OFL-bricolage-grotesque.txt) |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | poids 500 à 700 | [OFL-jetbrains-mono.txt](OFL-jetbrains-mono.txt) |

Source : Google Fonts, sous-ensemble « latin » (lettres accentuées du français comprises), téléchargé le 2026-10-31. Licence SIL Open Font License 1.1 : redistribution permise avec le fichier de licence.

Pour ajouter une graisse ou un alphabet, retélécharger le fichier depuis `https://fonts.googleapis.com/css2?family=…` avec la plage voulue.
