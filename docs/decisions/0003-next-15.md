# ADR-0003 : Passage à Next.js 15.5 et React 19

## Statut
Acceptée

## Date
2026-10-31

## Contexte
La V0 tournait sur Next.js 14.2.35, la dernière version de la branche 14, qui n'est plus corrigée. `npm audit` y signalait des failles critiques (exécution de code à distance via l'API d'optimisation d'images, contournement du middleware, SSRF, déni de service). Elles ne sont corrigées qu'à partir de Next.js 15.5.28.

## Décision
- Passer à Next.js 15.5.28 et React 19.
- Forcer `postcss` ^8.5.32 dans `next` (`overrides` de `package.json`), car Next 15.5 embarque encore une version vulnérable.
- Rendre bloquant le contrôle `npm audit --omit=dev --audit-level=high` dans la CI.

## Alternatives envisagées
- **Rester en 14.x** : aucun correctif publié. Écartée.
- **Passer directement à Next.js 16** : corrige tout, mais apporte plus de changements cassants (middleware renommé, Turbopack par défaut). Reportée à une étape ultérieure.

## Conséquences
- Les pages lisent `params` et `searchParams` de façon asynchrone (`await params`).
- Il faudra retirer l'`overrides` de postcss lors du passage à Next.js 16.
- Les failles restantes concernent seulement les outils de test (vitest), pas le site en ligne.
